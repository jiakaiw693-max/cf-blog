这是一篇展示文章排版的示例。你可以参考这些写法，也可以删掉它，从一篇自己的笔记开始。

## 用段落展开一个想法

一个段落围绕一个意思展开，往往更容易读。先把想说的话写清楚，再决定哪里需要小标题，哪里适合放一段例子。

**需要强调的内容可以加粗**。如果希望读者继续了解某个主题，可以添加链接，例如 [Markdown 内容说明](https://docs.astro.build/en/guides/markdown-content/)。

## 用例子说明问题

一份笔记不必覆盖所有细节。一个具体的例子，常常就能帮助自己理解当前的问题。

### 记录一段代码

代码块可以保留缩进，也可以标注使用的语言。下面是一段简单的 TypeScript 示例：

```typescript
type Note = {
  title: string;
  tags: string[];
};

const note: Note = {
  title: '今天的一个发现',
  tags: ['学习'],
};

console.log(note.title);
```

### 留下一个检查清单

当内容确实是并列的项目时，可以用列表让它更容易检查：

- 我想解释的是什么？
- 例子能否说明这个问题？
- 以后回看时，是否还需要补充背景？

## 把未完成的思考留下来

记录不必一次完成。留下一段理解、一处疑问，以及下一次想继续研究的方向，就已经是一份有用的笔记。

> 写得清楚，比写得复杂更重要。
